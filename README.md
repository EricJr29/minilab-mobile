# 🔬 Minilab Mobile (Física & Sensores)

Um aplicativo mobile interativo desenvolvido para servir como um "minilab", unindo simulações de física e exploração de hardware do smartphone (sensores de movimento) em uma interface limpa baseada em rotas.

---

## 🎯 Sobre o Projeto

O **Minilab Mobile** foi criado para explorar o desenvolvimento mobile multiplataforma utilizando conceitos práticos de física e captura de dados de sensores. Através de um menu central, o usuário pode navegar entre diferentes módulos de experimentos e visualizações em tempo real.

---

## 🚀 Tecnologias Utilizadas

* **React Native:** Framework para construção da aplicação mobile.
* **React Navigation (@react-navigation/native):** Gerenciamento de rotas e navegação em pilha (*Native Stack*).
* **Expo APIs:** Acesso aos recursos nativos do dispositivo (como o Acelerômetro).
* **JavaScript / ES6+:** Lógica de controle e manipulação de estados.

---

## 📱 Estruturas de Telas (Módulos)

* **Início (`HomeScreen`):** Painel central de navegação para todas as ferramentas do minilab.
* **Gravidade (`GravityScreen`):** Simulações visuais envolvendo leis da física e aceleração.
* **Frequencia (`FrequenciaScreen`):** Experimentos voltados a ondas, ciclos ou taxas de repetição.
* **Acelerômetro (`AcelerometroScreen`):** Leitura em tempo real dos eixos de movimento físico do celular através dos sensores nativos.
